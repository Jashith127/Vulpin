# Vulpin interactive prototype

A responsive, dependency-free prototype built from the supplied PRD/concept, detailed user flows, mid-fidelity paper prototype, interaction documentation, and style guide.

## Run locally

From this folder, start any static file server. For example:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Primary journey

1. Continue as a demo learner.
2. Open a topic or create a new one.
3. Choose a deadline, depth, and learning goal.
4. Curate the source pool and generate the plan.
5. Study the topic and open the source trace.
6. Take the quiz; try both the hint and retry paths.
7. Review topic-level progress and choose what to study next.

All data and authentication are simulated locally for usability testing.
